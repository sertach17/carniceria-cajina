# Carnicería Cajina

Website for Carnicería Cajina, a family butcher shop in Barrio La Cruz, Chinandega, Nicaragua.

Live site: https://carniceriacajina.com

## What's here

- `index.html`: the main page (hero, history, products, quality, the store and how to visit).
- `galeria.html`: the photo gallery, opened from the Galería link and the "Ver galería de fotos" button.
- `img-v5/`: photos, product images, logos and icons.

It's a static site with no build step, deployed on Vercel from the `main` branch. Orders go through WhatsApp.
